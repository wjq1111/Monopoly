# Q 版棋盘头像 v001

状态：三张奶油底头像候选已生成并原样保存到工程；未确认为正式角色基准。采用不透明 PNG，不声称具有透明通道。本子任务完成参考查看、生成、文件核对与 48 像素并排预览；Godot 界面接入与最终场景验收由主任务另行记录。

## 范围与助手决定

本次为三花、布偶、奶牛各制作一张 Q 版棋盘小头像，遵循 [素材风格与生成规范](../素材风格与生成规范.md)。共同方向为正面圆头、大眼、只露猫头和少量肩部、暖绘本笔触、清楚轮廓与完整耳尖，最终约 48 × 48 像素显示。保持原故事三兄弟身份，不加衣服、道具、文字或新剧情。

| 决定 | 依据与影响 | 决定归属与状态 |
| --- | --- | --- |
| 从既有肖像派生 Q 版小头像候选，保留主要花纹和眼色 | 当前任务需要适合棋盘小尺寸的辨识度；Q 版比例与细节密度不同于原肖像 | 本轮制作范围；正式基准仍未确定 |
| 路径读取失败后，继续用内置工具生成仅受文字约束的新候选 | 本地参考接口报 Windows 1385；参考已经实际查看，但没有成功作为图像输入传入 | 助手替代执行方式，经主任务明确允许；不称精确依参考生成 |
| 将最初透明方案改成不透明奶油底头像章 | 用户要的是 Q 版小头像；透明是助手的临时技术选择，工具生成的棋盘格背景不符合该选择。改用便于当前界面展示的奶油底候选 | 助手展示方式调整；未改变猫的固定花纹，未声称用户确认每项制作参数 |
| 同组三张使用同一固定提示规格，分别生成 | 保持正面、比例、笔触和背景方向；不把新生成的三花自动作为后两张的新基准 | 助手一致性措施；仍需实际对照，不保证一次即正式合格 |

“Q 版棋盘头像 v001”是候选子规格。头部约占画幅 80%、目标背景 `#fffaf0` 等数值是本轮助手制作参数，并非原故事规定。当前输出背景接近奶油色，但不是精确平涂的 `#fffaf0`，差异如实记录在检查表。
