# 《我们的家》策划规则整理

更新日期：2026-09-05

状态：本文件是故事与规则依据，以用户已经确认的内容为准，保留原故事。工程已进入 M0 脚手架阶段，实施范围与后续顺序见[技术方案与实施计划](技术方案与实施计划.md)；文中规则不代表已经实现。原稿页码对应 docs 下的故事截图。

## 一、游戏范围与基本方向

- 名称：**《我们的家》**。
- 三名玩家分别扮演三花、布偶、奶牛；系统自动主持。使用 Godot。
- 三只猫保持原稿中的三兄弟关系，角色行动和普通骰子结果不可预知。原稿允许的重投、改点、控点、传送按技能处理。
- 月份可以持续推进、跨年循环。玩家可以反复获取食物、积累野性，不设置通关月份上限。
- 野性是经验值。等级不足时可以继续练级，只要能维持生存就能继续活动。
- 战斗前期困难、后期简单。前期遇到鹅、狗时可以逃跑，成长后再挑战；后期变强、战斗变容易是预期体验。
- 终战失败可以不限次数地获得原稿救场，最终让小猫获胜是既定设计目标。
- 不追加新的调查线索、人物身份、世界观、结局路线或养育系统。原稿已有的故事与技能保留。

## 二、角色数值、经验与觉醒

### 初始数值及术语

| 角色 | 默认等级 | 当前级经验 | 当前饱食度 | 饱食度上限 |
|---|---|---|---|---|
| 三花 | 1 | 0/10 | 3 | 5 |
| 布偶 | 1 | 0/10 | 3 | 5 |
| 奶牛 | 1 | 0/10 | 3 | 5 |

以上为用户确认的正式开局数值。新手期间的旧数值、上限增长与 1 级效果统一以这个起点为准，不在开局上限 5 上重复追加一次新手或 1 级奖励。后续筑巢、技能、道具与救场的上限增长另按各自条件结算。

**玩家只使用饱食度这一项生存数值。** 扣减、恢复、归零和上限增长统一使用“饱食度”表述，不再建立另一条玩家生存数值。本文敌方数值也统一以饱食度标记，大小仍沿用原图鉴。

### 经验成长

| 晋升 | 本级需要的经验 | 从默认 1 级起的总经验 |
|---|---|---|
| 1→2 | 10 野性 | 10 |
| 2→3 | 20 野性 | 30 |
| 3→4 | 30 野性 | 60 |
| 4→5 | 40 野性，且完成个人觉醒 | 100，且完成觉醒 |

经验按“当前等级、当前级经验”记录。升级后，多出的经验进入下一级进度。例如：1 级 0/10 获得 25 野性后，成为 2 级 15/20；再获得 5，成为 3 级 0/30。

到 4 级后仍可积累经验；未完成觉醒时保留经验，不跳过觉醒直接升 5 级。原稿与早期讨论中的其他升级数值不再使用。

### 觉醒自动安排

依据用户对“4 级、经验 0/40”的例子的回答，按以下规则执行：

1. **达到 4 级后，为该猫安排一次觉醒。** 不需要先攒满本级 40 经验，也不要求再次随机走到觉醒格。
2. **占用下一个属于该猫的行动回合**，自动移动到对应格子并触发原稿觉醒剧情。
3. 这次行动用于觉醒，不再另外赠送一次普通移动或地块事件。
4. 完成后记录觉醒已完成，不能在以后每个行动或每次到访时重复触发。
5. 完成觉醒后，经验也达到要求即可升 5 级；经验不足则继续积累。
6. 剧情中的“第二天”“七天后”按这一段故事叙述播放，不另外扣出数个游戏月份。

| 角色 | 自动前往的格子 | 原稿觉醒技能 |
|---|---|---|
| 布偶 | 17 号，墓地【30–31】 | 好好吃饭 |
| 奶牛 | 7 号，白沙池【31–32】 | 我是一只爸爸 |
| 三花 | 25 号，流浪猫聚集地【32–33】 | 第四种颜色 |

如果该猫的下一个行动到来时仍处于濒死、受困或其他不能行动状态，觉醒安排与该状态的先后还须补齐；不能丢失已经安排的觉醒，也不能重复发放觉醒效果。

## 三、月份与行动

### 每个月的基本顺序

1. 上旬：三只猫各行动一次。
2. 中旬：三只猫各行动一次。
3. 下旬：使用共享小猫仓库补给。
4. 进入新月，按新月份的季节结算基础饱食消耗。

| 季节 | 月份 | 每月基础饱食扣除 |
|---|---|---|
| 春 | 3、4、5 月 | 1 |
| 夏 | 6、7、8 月 | 2 |
| 秋 | 9、10、11 月 | 3 |
| 冬 | 12、1、2 月 | 3 |

这张表替代旧的新月、换季和冬季翻倍组合，不额外叠加旧规则。受伤翻倍与奶牛恢复技能属于角色效果，另按对应规则结算。

例如：5 月下旬补给后进入 6 月，基础扣 2；11 月下旬补给后进入 12 月，基础扣 3。

### 持续推进的约束

- 不假定某只猫在某个月必定达到某级、取得某件物品或到达某格。
- 等级、经验、主线完成情况、关系变化和已完成觉醒跨月保留。
- 等级或任务条件不足时，继续原有捕猎、训练、交易与探索。
- 允许原稿规定的日常重复收益；没有额外的月度经验上限或练级期限。
- 一次性剧情和奖励必须记录，不能把“可以长期刷野性”实现成同一次主线反复发奖。
- 一次行动尚有必须完成的选择或结算时，不应同时重复推进月份。
- 正式开局当前饱食度为 3，不由开篇叙述和月份系统重复扣除同一次月度消耗。

### 最终战入口

- 触发终战剧情与真正开始战斗是两件事。
- 剧情触发后，任意一猫到对应格即可选择是否开战，不要求三只猫自己走到一起。
- 选择进入时才强制集合全队；仅到格或查看剧情不会立即开战。
- 暂不进入不清除入口，之后仍可在符合到格条件时选择进入。
- 原稿“暂时撤退则前进 1”保留；作用于哪个棋子仍需在动作细则中明确。
- 结局之后是否还能继续月份或重打，不由战斗入口的保留规则自动推导。

### 幸福小区：主线优先

已重新核对原稿：

- 5.png 的寻母条件是“全部 2 级时在幸福小区触发”。
- 16.png 的被抓事件只写“布偶触发”，没有额外等级或主线阶段限制。
- 17.png 的“布偶后续触发”用于区分获救后的逃开重投。

因此，条件不同仍可能同时成立，例如全员至少 2 级时，布偶首次到幸福小区。

**用户已确认：本次主线优先，布偶个人事件留到之后到访。** 执行主线时不把布偶个人事件标为已完成；之后符合其原有条件再次到访，才处理个人事件。获救后的后续版本仍按原文执行。

其他地点也必须明确各事件的条件与完成标记，不能因事件同在一个格子就不加区分地全部执行。本次确认的具体裁定是幸福小区的这组事件。

### 强制移动的适用场景

| 场景 | 已确认处理 |
|---|---|
| 普通寻母主线 | 一猫到场触发共享剧情，其他猫原位 |
| 鹅、狗战斗中的“呼唤同伴一同应战” | 选择召集参战时，强制移动同伴到战斗地点 |

鹅、狗原稿仍有逃跑选项，不把“召集时强制移动”改成一遭遇就自动集合。被召集同伴是否扣除尚未使用的棋盘行动，尚未明确。

筑巢后“你叫回大哥和三弟”【8】仍只是原稿的集合叙述；本轮没有把它另定为一次全队传送。

## 六、战斗、逃跑、濒死与复活

### 战斗顺序与伤害

- **三只猫的战斗行动顺序，固定按开局玩家选择顺序。** 不按猫的名字另排固定顺序，不因等级或复活重新抽顺序。
- 多猫参战时沿用参战猫在该顺序中的相对位置。
- 对敌伤害 = 本次结算后的战斗骰点 × 当前猫等级。
- 例如 1 级掷出 4 点，造成 4 伤害；3 级最终骰点为 8，造成 24 伤害。
- 三花连投累加，奶牛按上一节公式结算，其他能力按原文作用范围处理。
- 本轮明确了猫之间的顺序；敌方在三猫行动之间还是之后出手、每轮次数、闪避选择与揭晓时点尚未指定，不能据此假定已经确认整套战斗轮次。

| 鹅大哥【13、20】 | 春夏秋 150，命中扣玩家 1；冬季 100，命中扣玩家 1.5；低于 50 后命中可让目标下一回合停行动 |

猫老大的“6 变 0”与奶牛改点、三花重投的先后仍须明确。

### 逃跑与受伤

| 情况 | 处理 |
|---|---|
| 可以执行逃跑 | 扣 1 饱食度，必定成功，不掷成功率骰 |
| 无法逃跑 | 进入濒死 |
| 正常状态发生原稿车祸或中炸弹【11、12】 | 进入受伤 |
| 已受伤再次发生上述事故【11、12】 | 直接进入濒死，不叠加更多层受伤 |
| 受伤状态消耗饱食【15】 | 每次消耗翻倍 |

饱食是玩家唯一生存数值，结算后归零必须接入濒死处理，不能保持为正常可行动状态。涉及奶牛先扣后恢复时，以最终确定的效果顺序判断是否归零。

逃跑后的具体棋盘位置、本次行动的结束时点，以及受伤时逃跑代价的翻倍处理仍需在动作细则中明确。

### 部分猫濒死：挂靠送医

原稿 19.png 的 20 号“宠物医院”四季营业，医生小可免费救治。原稿中的“濒三”在本文统一为“濒死”。

1. 有猫濒死，但仍有可行动同伴：濒死猫挂靠一名玩家。
2. 承载玩家携带它移动到 20 号医院，不自动直接传送到医院。
3. 医院免费解除对应状态，恢复 2 饱食度，结束该猫本次送医挂靠。
4. 受伤但还能自行活动的猫，也可以自己到医院，免费解除受伤并恢复 2。

**医院是原稿已有机制。** 单猫濒死送医与全队复活分开处理，不能因为已经有全队复活规则，就省略仍有人能够救援时的送医过程。

挂靠对象的选择、同时携带两猫、承载玩家也濒死时的转交，以及濒死期间可使用哪些操作，仍需补齐。

### 全员濒死：全体复活

用户已确认：**全员都倒下时直接全体复活，不等待无人能够完成的送医，不设永久全队失败。**

- 每次状态结算后三只猫均处于濒死状态时，进入全队复活处理；有猫只是受困或暂停行动时，不算全员濒死。
- 同一轮导致三猫倒下的结算，只触发一次全队复活，不能按每猫或每个客户端重复执行。
- 复活时解除濒死和对应挂靠，恢复到可以继续游戏的状态。
- 原稿直接写出的复活数值位于最终战失败段落，见下一节。
- 普通探索或普通战斗全员倒下也会复活，这是用户本轮明确的范围；其恢复数值、复活地点以及是否重开原战斗，原稿没有单列，仍需补齐。
- 不将终战额外奖励自动扩展为普通探索或普通敌人失败的奖励。

“全员都被关住或停止行动”与“全员濒死”不是同一个条件，不能错误地把任何短暂停行动都当成全灭。

### 最终战失败：原稿救场不限次数

已重新核对 9.png：“若失败则触发”位于最终战段落，明确写有重新开始战斗、全体恢复至上限复活、上限 +3、闪避位 +1，以及仓库获得 5 条鲢鳙。

结合用户“没有限制次数，最后一定能保证小猫胜利”的确认，本版按完整救场重复执行：

1. 记录本次最终战失败。
2. 三猫饱食度上限各 +3，按新的上限恢复饱食度，解除濒死与挂靠。
3. 闪避位置增加 1。
4. 共享小猫仓库获得 5 条鲢鳙。
5. 重新开始最终战。
6. 再次失败时可再次执行，不设置次数上限；上限、闪避位和补给按每次救场累加。

每次失败只能结算一次，但不同失败可以反复救场。这是让小猫持续获得帮助并最终胜利的原稿机制，不改为只有一次机会。

三花“第 4 闪避位”与救场增加位置、敌人全位置攻击的具体配合，仍需按技能动作细则统一。已经完成的主线和觉醒不因重试重新发奖。

### 战斗中的剧情阈值

原稿终战在敌方剩余 1500 时触发伙伴援助【8】。伤害直接跨过该数值也必须识别，不能只判断恰好等于 1500。图鉴中的“低于 800”等严格比较另按原文处理。

## 八、随机流程与剩余执行边界

以下检查只为保证已有玩法能够完整执行，不新增剧情或系统。

| 情况 | 必须保证的处理 |
|---|---|
| 提前到访后续剧情格 | 检查前置，不提前播放后续主线，也不删除以后触发资格 |
| 已有材料或猫条再接任务 | 按物品实际归属与交付规则检查，不假定玩家一定按编写顺序取得 |
| 练级超过寻母所需等级 | 按至少 2 级判断，不用恰好 2 级卡住主线 |
| 达到 4 级但始终走不到觉醒格 | 已解决：下一行动自动移动并觉醒 |
| 布偶首次到小区恰好满足主线 | 已解决：主线优先，个人事件留待以后到访 |
| 一猫到最终战入口 | 显示是否进入；确认进入后集合全队 |
| 鹅、狗选择呼唤同伴 | 强制移动同伴参战；棋盘行动如何计费仍待细化 |
| 一猫或两猫濒死 | 有可行动同伴时走挂靠送医流程 |
| 全部猫濒死 | 已解决：全体复活；普通复活的数值与地点需补齐 |
| 最终战反复失败 | 已解决：原稿救场不限次数，不消耗有限复活次数 |
| 布偶走 0 步、传送或使用红灯 | 明确是否重新触发区域、行动归属和区域风险判定 |
| 公交连续换乘或回家额外行动 | 明确当前行动何时结束，不自动在 10→23→16→10 之间循环 |
| 骰子经过某格但未停留 | 区分经过与落点，不重复执行同一到访 |
| 奶牛双骰与捕猎表同时存在 | 双骰不扩展到原本只按 1–6 查表的捕猎判定 |
| 同一任务被多人看到或重复点击 | 共用已完成标记，同一次奖励与消耗只执行一次 |
| 普通日常再次到访 | 原稿允许重复的收益继续提供，不一律增加冷却或次数限制 |
| 跨月、存档或重连 | 保留原进度；同一次扣除、奖励、复活不能再执行一次 |
| 猜大小、抽签、抽卡 | 明确平点、主动停止、放回与牌池用尽后的原玩法裁定 |
| 同伴受困、濒死或正在处理其他事件时被强制移动 | 明确状态、待结算事件和行动如何衔接，不能悄悄丢弃或重发 |

本轮已确认的内容均已从待答问题中移除。仍未明确的主要执行细节是：敌方行动与闪避时点、普通复活数值和地点、强制参战的棋盘行动消耗、个别技能组合和物资归属。没有把这些细节当作已获用户确认的规则。
