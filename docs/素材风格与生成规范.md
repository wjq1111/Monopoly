# 《我们的家》素材风格与生成规范

更新日期：2026-09-05

本文件约束美术、界面、动画和声音的制作行为。故事与身份以[策划规则整理](故事审阅与开工前条件.md)为准，开发顺序见[技术方案与实施计划](技术方案与实施计划.md)。

**当前状态：规范已建立，正式风格尚未确定。** 还没有作为制作基准的三猫设定图、配色表或声音样例。现有 Godot 预览界面的颜色和字体不自动成为正式风格。

一致性依靠固定基准、复用资源、对照检查和修正来维持。生成工具仍可能产生偏差，不能承诺每次生成都直接合格；能执行的约束是：发现偏离就修正，不把它悄悄纳入正式素材。

## 1. 先建立一套可查看的基准

先制作少量候选样例供比较：三猫角色样张、棋盘局部、主要界面，以及对应的短声音样例。结合用户反馈确定方向后，记录基准版本、实际文件、确认依据与日期。尚无方向时可以制作候选，不能将候选标为已确定的正式基准。

基准必须同时包含文字约束和可查看、可试听的样例：

| 范围 | 应固定的内容 | 当前状态 |
|---|---|---|
| 整体画面 | 绘画方式、轮廓与线条、纹理、明暗处理、主辅色及颜色值 | 待定 |
| 三只猫 | 各自花纹分布、脸型、耳尾形状、眼睛、体形比例、相对大小；按当前需求补充不同视角 | 待定 |
| 棋盘与场景 | 视角、透视、比例、光源方向、地块边界和前后遮挡关系 | 待定 |
| 图标与棋子 | 最终显示尺寸、留白、对齐点、轮廓辨识和缩小时允许省略的细节 | 待定 |
| 界面 | 字体与字号层级、颜色、间距、按钮形状，以及选中、禁用、等待等状态 | 待定 |
| 动画与特效 | 动作幅度、节奏、关键姿态、特效颜色及信息层级 | 待定 |
| 音频 | 音色与乐器方向、空间感、节奏、同类声音的音量关系及参考声音 | 待定 |

三花、布偶、奶牛的故事身份保持原稿。奶牛的技能名“我是一只爸爸”不改变三兄弟关系，也不能据此给他新增父亲身份或相关服饰道具。

同一基准允许明确的子规格，例如棋子、头像和剧情插图可采用不同细节密度。需要简化哪些花纹、保留哪些辨识特征应写清，不能临时凭感觉改变。场景气氛可以随原剧情变化，角色本身的固定特征继续保持。

## 2. 每次制作前必须读取并引用基准

1. 读取当前风格版本、该素材的用途，以及角色或场景的固定特征。先确定它是候选探索、增加同风格素材，还是修改已有素材。
2. 实际查看将使用的参考图；涉及声音时实际试听参考。缺少某个关键视角或部位的设定，先补充候选设定，不能把推测直接当成既定特征。
3. 将每份参考标明用途：整体风格、角色身份、构图或需要修改的原图。工具支持图像参考时，必须实际传入对应图像；在提示词里只写一个文件名不算已经使用参考。
4. 后续素材持续使用当前基准图。上一张生成结果可以作为修改对象，但不能自动替代基准，避免连续几轮后花纹、比例和颜色逐步偏移。
5. 如果工具无法接收必需的参考，说明限制，结果保留为候选。不得声称未传入的参考已起作用，也不得编造工具不支持的随机种子或风格参数。

图像生成与位图编辑使用当前可用的图像生成能力，并遵循其工具约束。已有 Godot 界面组件、矢量资源或动画轨道优先复用和修改对应源文件。不要把确定性的界面元素反复生成成互不一致的图片。

## 3. 提示词分为固定要求与本次变化

固定要求来自当前基准，后续任务沿用；本次变化只写当前需要的新姿态、表情、构图或环境。修正时一次针对一类偏差，并再次检查其他固定特征有没有被带动改变。

每次生成或修改保留以下记录；没有的参数写“工具未提供”，不要伪造：

```text
素材编号与用途：
本次任务：候选探索 / 同风格新增 / 修改已有素材
素材状态：占位 / 候选 / 已接入 / 已验收
风格版本与子规格：
实际输入的参考文件：
每张参考的作用：
必须保持：角色固定特征、画面方式、比例、配色等
本次允许变化：
不得引入：原稿没有的人物、身份、道具或剧情含义
输出要求：尺寸、透明背景、留白、朝向、对齐点等
完整提示词：
实际使用的工具与可见参数：
输出文件及版本：
对照检查结果与需要修正的问题：
```

例如，制作“三花的新表情”时，在已确定设定图的基础上只改变表情；具体花纹、眼睛颜色和体形继续取自基准，不能因为文字里只写了“三花猫”就重新设计一只猫。

相同提示词、相同工具或相同随机种子都不是一致性验收结果。工具版本或生成方式发生变化时，先用一个既有用途的样例对照，再决定是否扩大制作。

## 4. 界面、动画和音频采用各自的复用方式

**界面：** 将已确定的颜色、字号、间距和按钮状态写入共用 Godot Theme 或组件。新界面使用共用资源，需要新样式时同步补充规格，不在每个场景临时复制另一套参数。文字由实际界面排版，不依赖图片中的文字承担动态数值和操作信息。

**动画：** 复用已确定的角色图、姿态和对齐点。逐帧查看花纹、轮廓、大小是否跳变，再以实际速度检查动作。生成了一张姿态图不代表连续动画已经一致。

**音频：** 每组声音沿用对应的音色参考、用途、时长范围、空间感和音量关系。按钮、骰子、环境与音乐可以有不同作用，但需在同一场景试听它们是否协调。先调整已有合格声音或参数，再考虑重新生成；保存实际使用的来源与处理记录。

当前没有专用音乐或配音生成工具。相关文字设计不能标为已生成音频；未试听不能标为听感验收通过。今后工具可用时，仍需使用声音基准并完成试听。

## 5. 每个素材经过对照与场景检查

| 检查层次 | 必须核对的内容 | 不合格时如何处理 |
|---|---|---|
| 固定特征 | 与基准并排查看三猫花纹、体形、轮廓与相对比例；身份及故事含义保持一致 | 定向修正，不能靠其他优点抵消身份偏差 |
| 同组风格 | 与已验收的同类素材比较线条、配色、纹理、视角、光照或声音特征 | 保留基准，调整当前素材；不为迁就一张图重定义整套风格 |
| 文件规格 | 尺寸、透明通道、边缘、留白、对齐点、文件引用；声音格式、时长与实际参数 | 修正文件或资源配置后重新检查 |
| 游戏内表现 | 以实际显示尺寸检查清晰度、明暗底色上的边缘、中文排版和遮挡；实际试听音量、循环与切换 | 调整接入及表现；不能用原始大图或文件存在代替场景验收 |
| 整体流程 | 操作、动画、音效、剧情与当前状态相符，多次触发和切换后表现稳定 | 修复对应触发或播放问题，不修改故事规则来掩盖表现错误 |

检查结果按“通过 / 需修改 / 未检查”记录，并指出对应问题。固定特征或关键文件规格不通过时，不能将素材标为已验收。声音未试听、图片未查看的项目保留“未检查”。

结构和文件规格适合自动检查，视觉风格与听感需要实际对照。当前 `scripts/check.ps1` 只覆盖脚手架，不会自动判断素材风格一致；未来新增素材检查也不能冒充审美验收。

## 6. 版本、协作与风格变更

- 为素材保存稳定编号和版本，例如 `cat_sanhua_expression_v001.png`；文件名只是示例，不代表该素材已经存在。风格版本与素材版本分开记录。
- 多人或多个代理并行制作时，领取同一版本的基准与相应子规格；交付时附上实际参考和检查记录，不能各自重新解释风格。
- 未明确要求替换时，修改结果另存新版本；保留当前有效素材。明确要求替换后更新工程引用，并检查使用它的场景。
- 用户已确定方向后，常规补图、修边、接入与修正按既有授权推进，无需每张图再次确认。整体画风、三猫固定特征或声音方向的改变必须有用户的新要求或反馈依据；需要选择新方向时，先准备可比较的样例和影响说明，再请用户决定。
- 新基准生效时，列出受影响的素材并逐步统一。旧版仍未替换的部分标明过渡状态，不宣称全项目已统一。
- 素材继续使用[协作规范](../CONTRIBUTING.md)中的占位、候选、已接入、已验收状态。风格验收是其中一项，不能替代功能、来源或最终游戏流程的检查。
